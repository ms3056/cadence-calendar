# Changelog

Cadence Calendar is a fork and rebrand of [Calendar Plus](https://github.com/mattmaiorana/calendar-plus) (MIT, Matt Maiorana), itself a fork of [Liam Cain's Obsidian Calendar plugin](https://github.com/liamcain/obsidian-calendar-plugin). Release history before the rebrand lives with the upstream project.

## 1.0.0 — Cadence rebrand

- Renamed the plugin to **Cadence Calendar**: new plugin id (`cadence-calendar`), view type (`cadence-calendar-view`), ribbon icon (calendar-days), and settings section name.
- Reworked branding: README, CONTRIBUTING, SECURITY, and CHANGELOG rewritten for Cadence; Calendar Plus remnants (CSS classes `calendar-plus-wrapper`, icon ids, comment references) removed.
- Kept the upstream periodic-notes feature set: daily / weekly / monthly / quarterly / yearly notes, second daily notes, featured images, year navigator, dot styles, weekend shading.
- Updated LICENSE (MIT) to add Cadence's copyright line while preserving the upstream copyright notices, as MIT requires.
