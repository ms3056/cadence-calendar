# Cadence Calendar

A periodic-note calendar for [Obsidian](https://obsidian.md/) with integrated daily, weekly, monthly, quarterly, and yearly notes.

Cadence Calendar is a rebrand and further development of [Calendar Plus](https://github.com/mattmaiorana/calendar-plus) by Matt Maiorana (MIT), which began as a fork of [Liam Cain's original Calendar plugin](https://github.com/liamcain/obsidian-calendar-plugin). This fork renames the plugin to Cadence Calendar, reworks its styling, and keeps the periodic-notes functionality.

## Features

- A calendar view for navigating your vault by date — drag it to any sidebar, pin it as a tab, or pop it into its own window; placement is preserved across reloads.
- Built-in periodic notes for daily, weekly, monthly, quarterly, and yearly periodicities. Each has its own folder, filename format, and optional template — no separate Periodic Notes plugin required.
- Click a day cell to open or create that day's note; click a week-number cell for the weekly note; click the month/year/quarter labels to open or create those notes.
- **Second daily notes:** right-click a day cell (or Option/Alt + click) to create a second daily note independent of the primary one — its own folder, format, and template. A half-opacity dot marks days that have one.
- **Featured images:** optionally show a daily or weekly note's image as the calendar cell background (from frontmatter or the first embedded image), for a visual journal.
- **Year navigator:** an optional header button opens a compact 12-month grid for jumping between months and years.
- **Dot styles:** by default a dot means the corresponding note exists; the Dot style setting can switch to word-count dots plus an open-task dot for daily and weekly notes.
- **Weekend shading, week start, week-number side:** all configurable under Settings → Cadence Calendar.

## Settings

Settings are under **Settings → Cadence Calendar**. Each of the five periodic note types (Daily, Weekly, Monthly, Quarterly, Yearly) has its own Enable toggle, Date format, Folder, and Template file.

> **Folder names in date formats.** Your Date format may contain `/` to sort notes into subfolders, but the **filename** (the part after the last `/`) must identify the period on its own — Cadence Calendar reads the date back from the filename, not the folders. For example, `YYYY/MM/YYYY-MM-DD` works; `YYYY/MM/DD` does not (year and month would live only in folders).

## Install

**From a GitHub release (typical):** download `main.js`, `manifest.json`, and `styles.css` from the [latest release](https://github.com/ms3056/cadence-calendar/releases), copy them into your vault at `<vault>/.obsidian/plugins/cadence-calendar/`, then enable **Cadence Calendar** from Settings → Community plugins.

**With BRAT:** add `https://github.com/ms3056/cadence-calendar` to the [BRAT plugin](https://obsidian.md/plugins?id=obsidian42-brat) and enable it.

Cadence Calendar uses its own plugin id (`cadence-calendar`), view type, and ribbon icon, so it can coexist with the original Calendar plugin or Calendar Plus during a transition.

## Compatibility

Cadence Calendar requires Obsidian 1.8.7 or newer (inherited from the upstream fork).

## Development

```sh
npm ci          # install dependencies from the lockfile
npm run build   # lint and bundle to main.js (rollup)
```

`main.js` is generated by the build; edit `src/` instead. See [CHANGELOG.md](./CHANGELOG.md) for release notes.
